## Повторение программной проверки

Диагностика хранится в tools, вне production addon. Временно скопируйте:

- `tools/ME_CSH_Audit.c` → `ME_Conflict_Spawn_Helpers/Scripts/WorkbenchGame/WorldEditor/ME_CSH_Audit.c`.
- `tools/ME_CSH_AuditGame.c` → `ME_Conflict_Spawn_Helpers/Scripts/Game/ME_Conflict_Spawn_Helpers/ZZ_CSH_AuditGame.c`.

Имя ZZ обязательно: modded-диагностика должна загружаться после основного расширения класса. Откройте отдельную тестовую сессию addon.gproj и проверьте компиляцию. Через уже настроенный локальный Workbench NET API вызовите handler `ME_CSH_Audit` сначала с `action: open`, дождитесь загрузки, затем с `action: audit`. Первый вызов открывает тестовый мир; не используйте его поверх несохранённой пользовательской сцены. Второй временно создаёт/удаляет тестовые сущности и возвращает счётчики.

После проверки удалите только две временные копии из Scripts, оставив исходники в tools, и заново проверьте компиляцию чистого аддона. Эти диагностические файлы нельзя включать в публикацию.

## Дополнение: обзор HQ, 25.09.2026

Auto для CanBeHQ теперь сохраняет только крупнейшую композицию по площади XZ bounding rectangle. Во время перестроения временно создаются безопасные mesh-preview кандидатов, измеряются восемь углов bounds каждой mesh-сущности с учётом её world transform, затем переводятся в систему корня. Остальные preview удаляются. Общие min/max хранятся в локальной системе; жёлтый контур рисуется ONCE и следует позиции/повороту точки без масштаба, как сам preview. CSH_Clear сбрасывает наличие bounds; выключение и игровые переходы прекращают рисование.

Game и WorkbenchGame успешно скомпилированы в отдельной сессии Workbench 1.8.0.13: logs_2026-09-25_02-25-09; Game successfully created. Визуальная и программная runtime-проверка новой геометрии контура пока не проведены. Старый аудит ожидает три Auto-preview MOB: теперь для MOB ожидается один. Для ControlPoint/Harbor без GameMode прежние ожидания сохраняются.

Контур — консервативный прямоугольник доступной preview-геометрии, а не точный контур коллизий. Исключённые custom preview-prefab и выравнивание по рельефу по-прежнему не учитываются; соответствующие подписи сохраняются. На склоне контур лежит в плоскости маркера и рисуется без проверки глубины.
