# Changelog

Заметки к выпускам ME_Conflict_Spawn_Helpers. Английский блок предназначен для поля изменений Workshop; русский — для сверки. После публикации замените Unreleased фактическим номером версии и датой публикации. Не считайте дату подготовки датой выпуска.

## Unreleased — первый выпуск

Подготовлено 2026-09-25. Публикация ещё не подтверждена.

### English

• Initial release of Conflict Spawn Helpers for Workbench.
• Added composition previews for ConflictBase_MOB, ConflictControlPoint, and ConflictSourceBase_T1Harbor/T2Harbor/T3Harbor.
• Added automatic faction selection using the point's default faction and the Conflict GameMode's INDFOR mapping, plus manual US/USSR/FIA preview selection.
• Added a single largest-composition preview for HQ candidates and a combined rectangular footprint for the available variants.
• Added solid bright orange highlighting for construction-supply signs.
• Added preview toggling and cleanup during point deletion and Edit/Game transitions.
• Included a Workbench test world with faction-specific Harbor examples.
• Terrain alignment is not simulated; preview geometry can differ from the actual runtime composition.

### Русский

• Первый выпуск Conflict Spawn Helpers для Workbench.
• Добавлены голограммы композиций для ConflictBase_MOB, ConflictControlPoint и ConflictSourceBase_T1Harbor/T2Harbor/T3Harbor.
• Добавлен автоматический выбор по исходной фракции точки и настройке INDFOR в GameMode Conflict, а также ручной выбор US/USSR/FIA для предпросмотра.
• Для кандидатов в HQ добавлены одна крупнейшая композиция и общая прямоугольная зона доступных вариантов.
• Добавлена сплошная ярко-оранжевая подсветка табличек склада стройматериалов.
• Добавлены переключение подсказок и очистка при удалении точек и переходах Edit/Game.
• Включён тестовый мир Workbench с фракционными примерами Harbor.
• Выравнивание по рельефу не воспроизводится; preview-геометрия может отличаться от композиции после запуска миссии.
