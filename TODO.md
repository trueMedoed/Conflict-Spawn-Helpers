# Conflict Spawn Helpers — задачи

## Цель

Создать мод-помощник для разработчиков миссий Conflict в Arma Reforger Workbench: заранее показывать в World Editor места, которые займут объекты, появляющиеся только после запуска игры. Это поможет избежать размещения декораций и других объектов прямо на будущем объекте или слишком близко к нему.

## Исходные наблюдения автора задачи

| Точка / семейство prefab | Что появляется после запуска |
| --- | --- |
| `ConflictBase_MOB` | Палатка |
| `ConflictSourceBase_...Harbor` | Схрон с припасами и несколько дополнительных объектов |
| `ConflictControlPoint` | Палатка |

Это исходные наблюдения, а не проверенный каталог ресурсов. Точные имена Harbor-вариантов, состав объектов, условия появления и трансформации предстоит установить по текущей версии игры.

## Подготовка проекта

- [x] Создать отдельную папку проекта рядом с Vehicle Spawn.
- [x] Создать addon.gproj с собственным GUID и зависимостью от Arma Reforger.
- [x] Записать задачу и критерии приёмки.
- [x] Открыть addon.gproj в Workbench, выполнить первичное сканирование ресурсов (открытие подтверждено пользователем; resourceDatabase.rdb создан Workbench).

- [ ] Для каждой точки записать реальные prefab/GUID, локальные позиции, повороты, габариты и привязку к рельефу.
- [ ] Проверить зависимость состава от фракции, владельца базы и настроек миссии.
- [ ] Сопоставить настройки prefab с результатом запуска Conflict; отдельно проверить дополнительные объекты Harbor.

## Визуализация только в редакторе

- [ ] Выбрать подход: полупрозрачные голограммы будущих объектов либо debug shapes с контурами занятого объёма и подписью.
- [ ] Предпочитать чтение реальных настроек спавна; не подменять неизвестные размеры и смещения выдуманными значениями.
- [ ] Если точный preview недоступен, явно обозначать приближённую зону и причину неопределённости.
- [ ] Показывать все будущие объекты, а не только центр точки или палатку.
- [ ] Обновлять preview при перемещении, повороте, изменении свойств и удалении точки.
- [ ] Предусмотреть включение и выключение подсказок; проверить удобство отображения для выбранных и невыбранных точек.
- [ ] Исключить коллизию, сетевую репликацию, игровой спавн и сохранение вспомогательных объектов в миссию.
- [ ] Очищать временные shapes/preview при удалении точки, смене мира и переходе в Game mode.
- [ ] Сохранить штатное поведение Conflict; не менять игровые prefab ради отображения подсказок.

## Проверка и критерии приёмки

- [ ] Создать небольшой тестовый мир с тремя семействами точек и препятствиями рядом.
- [ ] Проверить компиляцию Game и WorkbenchGame в установленной версии Tools.
- [ ] Сравнить preview и фактический спавн для каждой точки: состав, позиция, поворот, габариты.
- [ ] Проверить повёрнутые точки, склон, копирование, удаление и undo/redo.
- [ ] Проверить повторное открытие мира и несколько переходов Edit → Game → Edit без дубликатов.
- [ ] Проверить, что сохранённая миссия не содержит вспомогательных сущностей и работает без помощника.
- [ ] Проверить одновременное подключение с ME_Vehicle_Spawn.
- [ ] Документировать ограничения и добавить скриншоты сравнения редактора и игры.

Готово, когда разработчик видит будущую занятую область всех трёх семейств точек до запуска миссии, а помощник не изменяет runtime-поведение игры.
