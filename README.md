# Conflict Spawn Helpers

Рабочая версия помощника для разработки Conflict в Arma Reforger Workbench. Показывает голограммы будущих композиций у баз до запуска миссии.

## Использование

1. Откройте `ME_Conflict_Spawn_Helpers/addon.gproj` в Workbench. Если проект был открыт до изменения скриптов, переоткройте его.
2. Откройте свою Conflict-сцену с настроенным CampaignFactionManager. Обычный FactionManager без SCR_CampaignFaction не содержит нужных настроек построек.
3. Разместите `ConflictBase_MOB`, `ConflictControlPoint` или `ConflictSourceBase_T1Harbor/T2Harbor/T3Harbor`. Подсказки включены по умолчанию и обновляются для видимых точек.
4. В меню Plugins → Conflict Spawn Helpers доступны команды:
   - **Toggle Conflict spawn previews** — включить/выключить подсказки.
   - **Cycle Conflict preview faction (Auto/US/USSR/FIA)** — переключить вариант композиции без изменения фракции миссии.

В Auto используется назначенная исходная фракция обычной точки. Если она не задана, читается INDFOR из текущего SCR_GameModeCampaign — как при InitializeBases в самой игре. Ключ FIA не зашит в автоматический выбор. Для кандидатов в HQ режим Auto показывает одну композицию с наибольшей площадью охватывающего прямоугольника и жёлтый прямоугольный контур геометрии всех доступных вариантов. Подпись предупреждает, что итоговая фракция может занять меньше места; для отключаемых невыбранных HQ сохранена соответствующая пометка. Контур перемещается и поворачивается вместе с точкой. Ручной выбор US/USSR/FIA показывает только выбранный вариант, без общего контура. Для обычной точки с неопределённым владельцем остаются все уникальные варианты из фракций сцены.

## Что реализовано

- Чтение настоящих prefab из `SCR_CampaignFaction.GetBuildingPrefab`: SERVICE_HQ для баз и SERVICE_SOURCE_BASE для источников припасов.
- Preview целой композиции через штатный SCR_BasePreviewEntity: палатки, склады, навесы и прочие элементы, включённые в её preview-данные.
- Обновление положения и поворота; перепроверка конфигурации раз в секунду.
- Editor-only, без переопределения игрового спавна, без физики и traceable-флага на вспомогательных объектах.
- Очистка при удалении точки, переключении подсказок и событиях перехода Edit/Game.

Скрипт охватывает компоненты типов BASE и SOURCE_BASE, поэтому может работать и с другими наследниками этих баз, помимо пяти проверенных prefab.

## Проверено и ограничения

Проверено нативным компилятором Workbench **1.8.0.13** и программной проверкой в World Editor 25.09.2026: пять целевых prefab, создание реальной mesh-геометрии, перемещение/поворот корня, фракционные варианты, отключение/включение, очистка, отсутствие физики и новых editor source-сущностей. Подробности — `docs/VALIDATION.md`.

**Выравнивание по рельефу пока не воспроизводится.** В игре SpawnBuilding дополнительно вызывает SnapToTerrain и SetTransformWithChildren. Текущий preview показывает prefab в позиции/ориентации маркера; высота и наклон отдельных объектов могут отличаться от runtime. В подписи это обозначено как `terrain alignment not simulated`.

- Штатные preview-данные могут быть упрощены. Нестандартные preview-prefab пропускаются с пометкой `partial`, чтобы не запускать их компоненты.
- Изменения prefab на диске могут требовать выключить/включить подсказки или переоткрыть мир после пересканирования ресурсов.
- Переключатель фракций содержит vanilla-ключи US/USSR/FIA; Auto читает также пользовательские SCR_CampaignFaction.
- Пользователь подтвердил визуальное отображение голограмм и контура HQ, удаление и undo/redo, сохранение/повторное открытие без лишних объектов, очистку и восстановление подсказок при Edit → Game → Edit (25.09.2026).
- Точное совпадение с игровым спавном на разных поверхностях и совместимость с Vehicle Spawn ещё требуют проверки.
