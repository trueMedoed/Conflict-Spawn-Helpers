# Conflict Spawn Helpers

Заготовка мода-помощника для разработки миссий Conflict в Arma Reforger Workbench.

Планируемая функция: показывать в World Editor объекты или занимаемую ими область, которые появятся в игре у `ConflictBase_MOB`, `ConflictSourceBase_...Harbor` и `ConflictControlPoint`.

**Текущий статус:** создан каркас addon-проекта. Голограммы, debug shapes и автоматическое обнаружение точек пока не реализованы. Открытие проекта в Workbench подтверждено пользователем. Проверка компиляции будущих скриптов и визуализации предстоит после их реализации.

## Начало работы

Открыть `ME_Conflict_Spawn_Helpers/addon.gproj` через Arma Reforger Tools / Workbench и дождаться сканирования ресурсов. Пока проект не добавляет команд редактора и не меняет игру.

Структура и базовая зависимость взяты по образцу соседнего проекта `Vehicle Spawn/ME_Vehicle_Spawn`. Новый addon имеет собственные ID и GUID и не зависит от Vehicle Spawn. Сгенерированную базу ресурсов создаёт Workbench.
